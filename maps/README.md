# Maps

CarX Drift Racing Online 2 local maps, converted from KinoMod (DRO1) maps.

Each map is a zip on the [Maps release](https://github.com/prevaildrifting/Prevail-Mod-Menu/releases/tag/maps)
(GitHub rejects files over 100 MB, so maps can't live in this folder directly).
`index.json` lists every map with its version, size and SHA-256.

**Install by hand:** unzip into `<CarX Drift Racing Online 2>\Mods\` so you get `Mods\<MapId>\<MapId>.json`.
Then in game: Freeride > Track Selection > Mods.

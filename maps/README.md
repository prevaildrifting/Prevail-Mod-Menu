# Maps

CarX Drift Racing Online 2 local maps, converted for Prevail. Each map credits its original author.

**The Prevail menu downloads and updates these maps automatically.** Join a room on one of them, or open the maps list
in the menu, and it installs the map for you (checked against its SHA-256 before anything is written).

| Map | Folder | Version | Author / credit |
|---|---|---|---|
| ADC Lake v2 | `ADCLakeV2` | 5 | Author Unknown, reuploaded by Prevail Drifting |
| DRO1 Red Rock | `DRO1RedRock` | 2 | Original track by CarX Technologies, DRO2 conversion by NVA (reuploaded by Prevail Drifting) |
| Smotland | `Smotland` | 5 | Author Unknown, reuploaded by Prevail Drifting |
| YZ East | `YZEast` | 1 | Author Unknown, reuploaded by Prevail Drifting |

## Install by hand (fallback)
1. Close the game.
2. Download the map's zip from the [maps release](../../releases/tag/maps).
3. Extract it into `<game folder>\Mods\` so you get `Mods\<Folder>\` (the zip already contains that folder).
4. Start the game: Freeride > Track Selection > Mods, or pick the map in Create room.

If an author asks for a map to be taken down, it is removed.
